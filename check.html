      How to Find Your CPU

      💻 On Windows:

      1. Press Windows Key + R to open Run
      2. Type msinfo32 and press Enter
      3. Look for "Processor" in the System Summary
      4. Example: Intel Core i7-9700K or AMD Ryzen 5 5600X

      Alternative: Right-click "This PC" → Properties

      💻 On macOS:

      1. Click the Apple Menu (top-left)
      2. Select "About This Mac"
      3. Look for "Chip" or "Processor"
      4. That value is your CPU

      Example: Apple M1, Intel Core i5, or similar

      ×

      How to Find Your GPU

      💻 On Windows:

      1. Press Windows Key + R to open Run
      2. Type dxdiag and press Enter
      3. Go to the "Display" tab
      4. Look for the "Name" field
      5. That is your graphics card

      Example: NVIDIA GeForce RTX 3070 or AMD Radeon RX 6800

      💻 On macOS:

      1. Click the Apple Menu (top-left)
      2. Select "About This Mac"
      3. Open "System Report..." if needed
      4. Look for "Graphics" or "GPU" under hardware details

      Example: Apple M1 integrated GPU or external AMD/NVIDIA GPU
