# CompatiX

CompatiX is a PC and laptop compatibility engine that instantly checks whether your system can run a given game or application. Enter your specs, search for any title, and get a clear side-by-side comparison against that title's minimum and recommended requirements — no login required.

🔗 **Live site:** https://s-a-mowlana.github.io/CompatiX/

## Features

- **Compatibility Checker** — compare your CPU, GPU, RAM, Storage and OS against a title's requirements for a clear Compatible / Not Compatible verdict
- **Games & Apps Library** — browsable, filterable collections with cover art and detailed requirements pages
- **Specter** — an AI assistant that explains results and answers hardware questions
- **Build Advisor** — hardware suggestions by budget or by a specific game/app

## Tech Stack

- HTML & CSS
- Game/app data via [RAWG](https://rawg.io/apps)
- AI assistant powered by [Groq](https://groq.com/)
